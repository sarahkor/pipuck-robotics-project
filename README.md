# PiPuck Robotics Project

This repository contains robotics projects and experiments developed using the PiPuck (e-puck2) platform.

## Documentation

- [Getting Started with PiPuck](GETTING_STARTED.md) — Setup, SSH connections, Wi-Fi, sensors, cameras, charging, and troubleshooting.
- [Early Experiments](early_experiments/README.md) — Initial experiments with robot movement, obstacle avoidance, and IR-based leader–follower coordination.
- [Main R&B Mission](main_rab_mission/README.md) — Cooperative multi-robot navigation using Range & Bearing, Wi-Fi communication, leader election, and obstacle avoidance.

## Project Structure

`early_experiments/` contains the initial robotics experiments.

`main_rab_mission/` contains the complete cooperative Range & Bearing mission for two or three PiPuck robots.

For instructions on setting up and connecting to the robots, start with [GETTING_STARTED.md](GETTING_STARTED.md).
